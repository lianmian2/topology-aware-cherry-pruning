# 樱桃树综合分析系统 (综合整合版)

## 简介
本系统将之前分散的五个独立的图形交互界面（GUI）整合为一个统一的综合系统，并同时接入了两套骨架相关流程：一套是旧版“`原图 -> ROI -> 枝条分割 -> 直接细化`”骨架检查流程，另一套是基于 `TreeTopologyBuilder2D` 的 2D 拓扑图构建流程。用户可以在一个界面中自由选择并叠加多个处理功能，所有算法将智能分析依赖关系，按正确顺序执行推理，并将结果叠加在同一张图片上。系统还内置了结果缓存和鼠标视图控制功能，极大地提升了交互体验。

当前统一 GUI 的条带分割模块默认加载 `Tape_Segmentation_V2/outputs/best_model.pth`。

整合的七个功能模块包括：
1. **条带分割**：识别并提取图片中的标定带（保留最大Y轴区域，过滤断开和背景噪声）。
2. **树枝分割**：通过 ROI 提取樱桃树主体，然后利用 CS-Net V2 进行树枝分割。
3. **主干提取**：在树枝分割的基础上，利用形态学和垂直跳跃连接算法分离出主干（红色）与普通枝条（绿色）。
4. **全图芽点检测**：对 ROI 区域进行滑窗推理，检测全图的花芽和叶芽，并自动进行 NMS 与交并比过滤去重。
5. **局部芽点检测**：支持在原图上通过鼠标拖动画框（256x256），仅对框选区域进行精准的芽点检测（与全图检测互斥）。
6. **直接细化骨架**：走旧版快速骨架检查流程 `原图 -> ROI -> 枝条分割 -> 直接细化`，并默认执行一次短毛刺裁剪，用于快速查看分割结果的骨架质量。
7. **2D 拓扑图构建**：基于 `trunk_mask`、`branch_mask` 和全图芽点中心构建连通的 2D 树拓扑图，执行 `树枝/主干骨架分离 -> 端点/分叉点初始化 -> 断裂段重连 -> 有向图构建`，最终得到可视化叠加结果与 `networkx.DiGraph`。

另外，`main_gui.py` 现已新增 **黑底结构视图** 选项：
- 条带分割：白色
- 枝条分割：白色
- 主干提取：主干蓝色，其余枝条白色
- 芽点检测：保持原有花芽/叶芽颜色
- 其余未被这些结果覆盖的区域：黑色

## 代码结构
为保证代码的可维护性和模块化，我们将核心逻辑进行了拆分：
- `main_gui.py`：主程序入口，包含 Tkinter 界面、事件绑定（包括滚轮缩放与右键平移）、多线程处理、结果缓存机制及图像叠加显示逻辑。
- `logic_models.py`：模型管理器（单例模式），负责所有 PyTorch 模型（ROI、枝条、条带、芽点）的延迟加载和显存管理。当前条带模型默认指向 `Tape_Segmentation_V2/outputs/best_model.pth`。
- `logic_roi.py`：负责调用 MMDetection 进行 ROI 黑底过滤。
- `logic_tape.py`：负责调用 SMP U-Net 进行标定带语义分割及 Y 轴过滤。
- `logic_branch.py`：负责调用 CS-Net V2 进行树枝二值化分割。
- `logic_trunk.py`：负责调用动态算法分离主干和枝条。
- `logic_bud.py`：负责 HRNet 芽点检测模型的滑窗推理（全图）与局部推理，包含相交处理与去重算法。
- `logic_skeleton.py`：负责统一 GUI 的骨架相关封装，既包含旧版直接细化骨架流程，也包含 `TreeTopologyBuilder2D` 拓扑构建与可视化适配。
- `tree_topology_builder_2d.py`：2D 拓扑核心构建模块，内部执行骨架分离、端点/分叉点提取、A* 断裂重连和图结构导出。
- `topology_annotation_gui.py`：手工骨架与分叉点标注工具，当前主用于“原图 -> ROI -> 枝条分割 -> 直接细化”结果的人工对照与阈值筛选。
- `batch_export_binary_skeletons.py`：批量导出骨架对比结果的脚本，支持同时导出旧骨架与“枝条+条带”新骨架。
- `batch_export_binary_skeletons_gui.py`：`batch_export_binary_skeletons.py` 的图形化入口，支持选择输入/输出根目录并保留原始文件夹层级。

## 依赖关系、缓存与叠加逻辑
本系统实现了**智能依赖处理与内存缓存机制**：
- 如果勾选了 **主干提取**，系统将自动在后台先执行 **树枝分割**（即使未勾选）。
- 如果勾选了 **树枝分割**、**主干提取**、**全图芽点检测**、**直接细化骨架**、**2D 拓扑图构建** 或 **ROI 边界显示**，系统将自动在后台先执行 **ROI 背景过滤**。
- 如果勾选了 **直接细化骨架**，系统将自动前置执行 **树枝分割**，然后直接对 `branch_mask` 做细化与短毛刺裁剪。
- 如果勾选了 **2D 拓扑图构建**，系统将自动前置执行 **树枝分割**、**主干提取** 和 **全图芽点检测**，然后基于 `trunk_mask + branch_mask + bud_centroids` 构建拓扑图。
- **内存缓存**：当对同一张图片执行过 ROI、枝条分割、主干提取、直接细化骨架或全图芽点检测后，结果会被缓存在内存中。后续追加勾选新功能（如 2D 拓扑图构建）时，系统会秒级调用缓存数据，无需重复进行耗时的模型推理。切换图片时缓存会自动清空。
- **全图芽点检测** 与 **局部芽点检测** 在界面上是互斥的，勾选其中一个会自动取消另一个。

**可视化叠加（Blend）方案**：
系统采用底图为原图，半透明叠加各层 Mask 和 BBox，并支持缩放平移：
- 条带：黄色半透明覆盖
- 树枝（仅勾选树枝）：蓝色半透明覆盖
- 主干提取：主干为红色覆盖，其余枝条为绿色覆盖
- 芽点检测：花芽（红色 BBox + 红色 Mask），叶芽（绿色 BBox + 绿色 Mask）
- 局部检测框：红色线框标识检测区域
- 直接细化骨架：青色细线骨架
- 2D 拓扑图构建：在结果图上叠加主干锚点、枝条骨架重连结果、拓扑节点和边，用于检查树干到枝条再到芽点的连通关系。

**黑底结构视图模式**：
- 条带与枝条统一显示为白色
- 主干显示为蓝色
- 芽点检测的框与 mask 颜色保持不变
- 最终结果不再与原图做透明混合，而是直接输出黑底结构图

## 交互操作说明
- **鼠标左键拖拽**：在原图区域拖动红色方框，以移动“局部芽点检测”的目标区域。
- **鼠标滚轮**：在原图或结果图区域滚动滚轮，可对图像进行**同步缩放**（放大/缩小），方便查看细小芽点和拓扑箭头。
- **鼠标右键拖拽**：在缩放放大后，按住鼠标右键并拖拽可对图像进行**同步平移**。

## 运行方式
```bash

cd <repository-root>/code/unified_system

```

## 注意事项
1. **显存消耗**：同时勾选所有功能会依次加载 4 个以上的深度学习模型。由于使用了模型单例和顺序推理机制，显存峰值被控制在合理范围，但仍建议拥有至少 8GB 显存的 GPU。
2. **全图检测耗时**：全图芽点检测采用滑动窗口推理，计算量较大，耗时可能在十几秒到几十秒不等，请耐心等待，界面上方有进度提示。
3. **模型路径**：所有模型权重文件的绝对路径已在 `logic_models.py` 中写死，若移动了模型文件夹，请同步修改其中的路径配置。

# Reproduction protocol

1. Verify all package files against `checksums/SHA256SUMS.txt`.
2. Create the locked software environment after the release-specific dependency file has been generated.
3. Use the source-grouped ROI/woody and bud manifests, the tree-level tape split, and the pruning nested-CV fold manifests exactly as supplied.
4. Run perception, tape support, topology routing, bud attachment, and pruning feature construction in pipeline order.
5. Reproduce paper tables from the supplied out-of-fold predictions and structural result summaries before retraining models.

The current package is a candidate, not a DOI-bearing archival release. A clean-environment smoke test, dependency lockfile, licence approval, and final review of manual pruning labels are required before publication.
